# FeralKey 0.10 验证记录

环境：macOS / Apple Silicon，2026-10-30。

- 协议、额度客户端、768 项额度/报告检查、761 项功能检查及模型安全检查通过。全部硬件输出使用模拟传输，额度读取使用本地夹具。
- 多彩覆盖所有基础图案；检查多彩音乐、零亮度、有效报告编码以及 Agent 颜色与启用状态保留。音乐键盘预览与实体合成使用相同的固定额度优先规则。
- 帧率测试使用可控制的单调时钟，模拟 10ms USB 完成延迟。在 60 FPS 下，下一帧按提交起点准时获得发送机会；设备忙时不追加帧。检查运行中切换 45 FPS、旧 30 FPS 默认迁移及显式 60 FPS 的保存。
- 音频包络比较 30/60 次每秒下相同实际时间的回落，结果一致；原有频率定位、静音、非法 PCM、采样率和不同灵敏度检查继续通过。
- 旧整板模式快照通过基础分区恢复，检查未关闭两组 Agent。持续动画、通知五秒后恢复、断连与旧回调隔离等检查继续通过。
- 界面离线截图检查：明亮主题的基础多彩开关与彩虹键位；深灰主题音乐页直接显示键盘、开关、灵敏度和 45 FPS 选择，无频谱柱状图。预览使用独立应用标识，不复用日常版的权限身份。
- 正式发布包重新编译、签名验证、归档完整性及当前源码一致性校验；打包回归检查源码排除凭据、越界链接，以及失败时保留旧应用。

本次没有向 RK98 发送新的测试帧，也没有启动真实系统声音采集。45/60 FPS 为软件目标与模拟调度结果，不是设备实测值；实际流畅度和多彩效果仍待用户验收。
