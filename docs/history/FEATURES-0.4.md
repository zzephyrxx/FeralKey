# FeralKey 0.4

## 额度自动更新

默认打开自动刷新，每分钟读取。可选 30 秒、1/3/5/10/30 分钟，开关和间隔在本机记住，页面显示下一次读取倒计时。手动刷新独立于自动开关；演示暂停本次自动读取，但不会改变下次启动的偏好。

实体灯条的自动同步默认关闭。连接并读取真实额度后，打开「自动同步实体灯条」，确认可能持久保存的风险。只有颜色变化、达到所选间隔、数据有效、非演示且没有通知正在显示时才写入。重连、暂停自动读取、应用基础灯效后自动关闭。网络失败保留实体最后一次快照，屏幕显示未知；不把失败状态猜成满额。

可通过两次自动读取时间变化来验证；无需按刷新。修改间隔会重排下一次读取，长间隔不会被旧的三分钟超时规则提前判为失效。

## 指定键区的通知

在「灯效与通知」打开选键，点击键盘添加或移除；「右侧数字区」一键恢复区域。提供光框、十字、棋盘三种预设和自由绘制；自由绘制点亮所有选中键，支持自选颜色。预览只更新屏幕，实际通知需已有本次连接的灯光或额度灯条作为恢复基准。

通知在选定键区显示四秒，其他区域保留最近一次已知静态颜色，然后恢复之前的完整灯光报告。动态基础效果在通知期间暂用静态底色。额度自动同步让出通知时段，避免相互覆盖。通知至少间隔十秒；外部链接仍需要本次确认。

## 系统音乐

进入音乐实验室后默认开始连接当前系统播放声音；可以关闭「进入时自动连接」，或停止跟随。首次由系统要求屏幕与系统音频录制授权，授权后可能需退出重开。

使用 [ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit)，只注册音频输出，不注册画面输出、不采集麦克风；只计算 RMS 音量，不保存或上传音频。排除 FeralKey 自身提示音，约每秒二十次更新；没有声音时预览回落。受保护内容或部分音频设备可能不能采集，采集中断显示错误并允许重试。

目前驱动屏幕预览，尚未向 RK98 高频发送保存配置命令。真实系统音频采集的授权、设备兼容性和受保护媒体需要用户环境验收，构建及数学测试不能替代实测。

## 自定义组合键与预设

选择一个实体键，再从普通主键和四个修饰键 ⌃⇧⌥⌘ 组合。加入列表后确认应用完整映射，Fn 槽仍不可覆盖。配置导入与最终编码都检验允许的基础键及修饰位，不再只允许六个固定组合键。

| 预设 | 默认组合 | 适用条件 |
| --- | --- | --- |
| 粘贴并匹配格式 | ⌥⇧⌘V | 应用需要支持对应命令 |
| Finder 移动文件 | ⌥⌘V | 先复制文件，再到目标文件夹使用 |
| 区域截图到剪贴板 | ⌃⇧⌘4 | 进入选择区域模式，结果可直接粘贴 |
| 截图与录屏面板 | ⇧⌘5 | macOS 系统截图工具 |
| 表情与符号 | ⌃⌘空格 | 系统字符面板 |
| 恢复关闭标签页 | ⇧⌘T | 浏览器需支持此默认快捷键 |
| VS Code 格式化文档 | ⇧⌥F | 需要对应语言格式化器 |
| VS Code 全部匹配多光标 | ⇧⌘L | 先选中文字 |
| VS Code 命令面板 | ⇧⌘P | VS Code 默认键位 |

来源：[Apple 快捷键说明](https://support.apple.com/en-us/102650)、[Apple 截图说明](https://support.apple.com/guide/mac-help/mh26782/mac)、[VS Code 默认快捷键](https://code.visualstudio.com/docs/reference/default-keybindings)、[VS Code 多光标与格式化](https://code.visualstudio.com/docs/editing/codebasics)。这些是有文档支持的常用动作，不声称经过需求量排名。软件自定义快捷键和输入法可能影响结果。一次映射是同时按下的组合键，不是多步宏。

## 验证

`scripts/test.sh` 覆盖旧协议、组合键字节、预设、图案区域隔离、RMS、自动同步确认/节流/去重、通知优先/恢复、长间隔有效期和连接失败保护。`scripts/test-auto-refresh.sh` 实际等待 30 秒，验证无需手动点击便会再次读取；只运行本地模拟 Codex。所有 HID 用模拟传输，不改变实体键盘。`tests/PackagingTests.py` 在隔离源码副本中检查新资源与打包边界。

更新仍使用本地临时签名。若输入监控开关开启却连接失败，按 `docs/PERMISSIONS.md` 移除旧条目并添加最终构建。请先测试一项组合键和一次通知，确认布局及恢复正常，再开启实体自动同步。
