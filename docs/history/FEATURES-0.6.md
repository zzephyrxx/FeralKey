# FeralKey 0.6

## 更短的页面

额度页默认只显示双进度条、刷新、配色、固定与同步；位置编辑和数据源状态折叠。基础灯效与通知使用两个页签。音乐页只保留音量历史、灵敏度和播放控制。改键页保留组合键编辑与应用，普通映射和工作流折叠。授权、教程和协议详情按需展开，风险确认仍在实际写入前显示。

工作台显示当前 RK98 的识别/连接状态，以及匹配的适配档案：100 个物理键位、RGB 整板/逐键灯光、普通键可重映射且保留 Fn、无独立宏键。键数来自布局资源，能力来自当前已匹配型号的协议资料及拥有者提供的信息；并非实时探测所有键盘的能力，不能外推到未知硬件。未连接时不会标为已连接。

## 模式与颜色修复

上一版默认开启区域隔离，却直接禁用了固件模式选择。本版把区域预设和整板固件模式拆成独立入口，基础预设不再锁死。

基础区域可选常亮、渐变、呼吸、跑马灯、代码雨。选色绑定基础 RGB 本身，不再复用可能被通知/音频预览覆盖的颜色值；选择固定颜色也会清除随机多彩标志。常亮、渐变可点击「应用颜色」，保留额度和通知区。亮度只调基础区域。

「整板固件模式与更多设置」内可选择公开固件模式，包括持续跑马灯。点击「应用整板固件模式」会明确确认取消固定额度、实体自动同步及独立通知区域，避免暗中覆盖固定功能。选择控件本身不发送报告，部分固件模式本身使用内置彩色，未必遵从固定颜色；需实物验证。

## 统一动态预设

跑马灯是横向移动光带，代码雨是按列错相下落的带尾迹雨滴；两者都是随时间变化的帧，不是静态雨滴的改名。基础区域与通知区域共用空间渲染器，区域通知只改变已选键。屏幕预览约 24 FPS，固定额度优先于通知，通知优先于基础区域。

**RK98 实体动态暂为有界实验。** 复核的 [Rangoli 配置保存流程](https://github.com/rnayabed/rangoli/blob/master/src/keyboardconfiguratorcontroller.cpp) 与 [Kludge Knight 逐键编码](https://github.com/vinc3m1/kludgeknight/blob/main/src/models/LightingCodec.ts) 没有提供本机已验证的仅 RAM 实时接口，不能据此断言逐帧写入不磨损存储。本版只复用已允许的完整静态 RGB 配置事务，没有添加猜测的设备命令。

- 基础动态及音乐：用户确认后，实体试播最多 15 秒、最高 4 FPS；结束或停止后恢复最近已知静态快照。
- 动态通知：先主动开启「实体动态通知（实验）」；每次四秒。关闭开关、重连或发送失败会取消动态任务。
- 本次连接全部动态试播合计最多 240 帧；每帧八个报告。这只是限制写入次数，不证明对存储没有影响，也不是稳定的长期播放模式。达到上限后停止，不自动循环。
- 试播中恢复使用最新额度/静态快照，不会恢复旧额度。区域和颜色用本次试播的快照，编辑中的改动不会直接写入设备。
- 屏幕预览、改选预设和进入页面不启动实体试播。已验证的原生固件整板模式可持续播放，不需要逐帧发送。

## 音乐响应

旧图表把同一个音量乘以固定正弦图形，所以看似频谱，但各柱实际上一起变化。新版显示最近约两秒的真实音量历史，明确不称为频谱。声音使用噪声门、非线性压缩与瞬态增强，保留响度变化空间；灵敏度可调。键盘屏幕预览改为按高度亮灭的历史音量灯柱，静音时熄灭。

系统音频仍经 ScreenCaptureKit 获取，不使用麦克风，不保存或上传。音乐页可直接调整灵敏度；授权和自动连接设置收进展开区域。实体试播前先连接键盘、应用一次基础灯光并连接系统声音。

## 建议验收

1. 更新后若连接被拒绝，按 [权限说明](../PERMISSIONS.md) 更新临时签名对应的输入监控/辅助功能条目。
2. 基础灯效选常亮、关闭多彩影响（选色会自动处理）、选明显颜色并应用，观察基础区与固定额度区。
3. 选跑马灯、代码雨，先观察屏幕。接受写入范围后按需进行一次限时实体试播，结束应恢复静态灯光。
4. 通知页选数字区、代码雨，应用区域、开启实验动态通知，再测试四秒通知；其他区域及固定额度不应被覆盖。
5. 播放有明显停顿和鼓点的声音，音量历史应起伏，暂停后回落；将灵敏度调低不会再让所有柱长期顶高。屏幕响应和实体响应分开验证。

自动化验证全用模拟 HID；实体颜色、帧率、代码雨和系统横幅联动仍需拥有者实测。
