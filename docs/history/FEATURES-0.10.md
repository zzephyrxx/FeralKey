# FeralKey 0.10

## 基础灯效与 Agent

基础灯效新增「单色 / 多彩」。多彩以键盘位置生成彩虹配色，适用于常亮、渐变、呼吸、跑马灯、代码雨；预览、应用、恢复和音乐页使用相同配色规则。选择后仍需点击「应用基础灯效」，草稿不会偷偷改变实体。亮度为零时关闭基础区，已应用额度区继续保留自身颜色。

移除「整板固件模式」入口及其关闭额度、通知的操作路径。基础灯效不再主动关闭已应用的 Agent 组或清除其配置。没有额度分区的单色呼吸、跑马灯仍可内部使用原生模式；有额度或多彩时自动走分区合成，无需切换工作模式。旧版整板模式快照按基础配色恢复，不再恢复任意整板模式。

## 音乐页

直接显示键盘律动预览，移除独立频谱柱状图。保留手动开关、灵敏度、帧率与授权入口；每次启动仍默认关闭。内部继续分析真实 24 段系统音频频谱，没有改成模拟动画。键盘律动继承上次应用的单色/多彩与亮度；固定额度区保持优先。

## 帧率

可选 12 / 20 / 30 / 45 / 60 FPS，默认 45 FPS。旧版 30 FPS 在升级时迁移为 45，其他已有有效选择保留；新版明确选择的档位会保存，之后不再自动更改。运行中调档直接生效。

发送节奏按帧的提交起点计算，避免把 USB 发送耗时叠加成额外等待。仍只有一帧在途、事务不交错、不积压旧帧；设备忙时跳过渲染机会。系统音频分析上限同步提高至 60 次/秒，包络按实际采样间隔调整，避免提高帧率后灵敏度改变。

以上是目标帧率，不是 RK98 实测 USB 吞吐量。实际速度受系统音频回调、主线程负载与设备响应限制；若 60 FPS 不稳定，可选择 45 或 30。未改变 HID 指令格式。

## 验收顺序

1. 基础灯效选「多彩」并应用，应看到彩虹配色；已应用的 Agent 额度键应保持原色及百分比。
2. 切换呼吸、跑马灯、代码雨，多彩仍可使用，额度组与自动同步选择不应被关闭。
3. 音乐页只显示键盘效果。开启系统声音跟随，对比 45 与 60 FPS；关掉后恢复基础灯光。
4. 重开应用：基础配色、帧率和额度选择保留，音乐仍等待手动开启。旧临时签名更新后若权限失效，按 [权限说明](../PERMISSIONS.md) 添加当前版本。
