# FeralKey 0.9

## 音乐律动

每次启动应用，音乐开关默认关闭。进入音乐页、旧版本保存的启用状态都不会自动启动采集。主动打开开关并确认后，才连接系统声音；关闭后停止采集、清空频谱并恢复基础灯效。灵敏度和其他配置继续自动保存。

频谱横轴为固定的低频到高频，不再显示横向移动的历史音量。系统音频经 2048 点 Hann 窗 FFT，转换为 24 个对数频段；各频段独立响应，屏幕与键盘使用同一组频段数据。短暂的峰值标记逐步回落。

灵敏度控制细小节拍的触发阈值与起落速度，不作为柱子的高度上限。每个频段跟随近期能量自适应，压低持续高音量的底部，给鼓点和音色变化留出空间。静音、缺失采样与非法数据回落为零，不添加随机或横向滚动动画。

应用仍使用 0.8 的实时颜色发送通道与单帧在途策略。本版没有更换 HID 指令，也没有通过自动化向实体键盘发送测试帧。灯光的实际起落、颜色和设备兼容性仍需实际听歌验证。

## 设置交互

参考 [FanBar 官方界面截图](https://github.com/helson-lin/FanBar#-screenshots) 中的分组设置、行间留白与简洁状态表达，重新实现了应用内的折叠组件，保留 FeralKey 的明亮与深灰玻璃主题。没有引入 FanBar 的源代码、图标或截图作为应用资产。

折叠入口高度至少 54 点，标题、图标、行内空白以及右侧箭头都可点击。统一增加「展开 / 收起」、悬停背景和方向箭头；支持键盘按钮操作、辅助功能状态与系统减少动态效果设置。展开内容的控件独立操作，不会因为调整设置意外收起。

## 建议验收

1. 重开应用并进入音乐页：开关关闭，频谱不动，不启动声音采集。旧版的启用状态也应如此。
2. 开启音乐，播放一段鼓点明显的歌曲：各列在原地上下跳，鼓点后回落，不横向滚动。静音应回落至零。
3. 调整灵敏度，比较小节拍的触发与回落；关闭开关后应恢复基础灯效。
4. 点击任意折叠行中间空白或右侧文字，均能展开/收起；展开后操作滑块、选择器不会误折叠。
