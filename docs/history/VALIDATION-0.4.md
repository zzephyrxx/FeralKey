# 0.4 验证范围

## 软件验证

- 旧协议、额度窗口、配置边界、Codex 本地模拟进程与设备生命周期测试通过。
- 新增组合键的修饰位和基础键黄金字节测试，覆盖九个预设及四修饰键的所有组合；未知位、Fn 和非法键码拒绝。
- 图案测试确认选择区域外的颜色保持不变，三种预设与自由绘制不同，完整 RGB 事务通过校验；空区域拒绝发送。
- 模拟 HID 验证自动同步需确认、所选间隔节流、相同帧不重复发送、通知期间让出设备、四秒后恢复完整旧帧、长刷新间隔有效期、演示不写入及重连停用。
- `scripts/test-auto-refresh.sh` 真正等待了 30 秒：使用本地假 Codex，通过正常激活路径完成两次自动读取，没有手动触发第二次，再验证暂停状态。没有访问真实账号或 HID。
- RMS 测试覆盖静音、非有限输入、满幅与 -30dB；音频采集模块编译通过。音频回调、静音回落、失败及停止采用会话代次检查。
- 明暗主题原生视图检查覆盖自动刷新设置、通知选择和图案、自定义组合键及系统音频状态页。预览模式不采集系统音频，不改变设备配置。
- 隔离无 Git 源码副本的发布包回归通过：假凭据排除、资源白名单、原图保留、故意构建失败保留旧应用。

## 用户环境仍需验证

- 新构建的输入监控授权、真实控制接口连接。
- 系统屏幕与音频录制授权，实际播放声音、停止、静音、音频设备变化及受保护媒体行为。此版本未由自动化开启实际系统音频采集；不能把 RMS 单元测试当作实际采集成功。
- RK98 的组合键输出、区域图案位置与颜色、通知恢复、实体自动额度同步。
- 配置命令是否持久保存仍未知，实体自动同步默认关闭；没有启用高频音乐写入。

此记录只描述上述版本的软件检查，不将未观察到的实物效果标为成功。
