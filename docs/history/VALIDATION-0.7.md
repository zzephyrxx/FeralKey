- `scripts/test.sh` 通过：原协议检查、768 项额度/编码/发现检查、Codex stdio 异常处理、模型安全场景及 611 项功能检查。
- 发送规划器：首次完整 RGB 初始化；只在成功发送后记住模式；相同头部的后续帧只输出七个颜色包；全局参数变化、原生模式切换、重连会重新初始化；不完整事务在写入前拒绝。实际 HID 实现只在颜色流期间使用此优化，普通应用/恢复发送完整事务。
- 通知与区域：五秒结束恢复、静态图案呼吸但不硬熄灭、通知键待机参与基础灯光、固定额度保护、通知期间额度更新后不回退。模型测试使用真实 RunLoop 等待五秒。

- 应用使用 StateObject 持有唯一配置模型，避免场景重建时重新初始化状态；重新构建并进行指定明暗主题的离线渲染检查。
- 恢复：界面保留未应用颜色，设备恢复上次成功应用颜色；固定额度等待有效真实数据；失败保留用户选择；关闭的实体自动同步不因固定区开启而被重新启用；不自动重发九包改键配置，也不自动重放试播。
- 发现并修复演示额度池覆盖真实来源偏好的回归问题，加入断言后全套通过。各安全场景为明确验证其行为关闭自动恢复，专门的恢复场景则使用独立偏好域开启恢复。

- `tests/PackagingTests.py` 通过：隔离无 Git 源码副本构建；递归假凭据和外部链接排除；旧资源清理；失败构建保留有效应用；原 Logo 保留。
