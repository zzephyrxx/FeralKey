# FeralKey 0.9 验证记录

环境：macOS / Apple Silicon，2026-10-30。

## 音频与状态

`scripts/test.sh` 全部通过，包含 750 项功能检查、768 项额度/报告检查，以及协议、额度客户端和模型安全检查。

新增 PCM 测试使用本地生成的 93.75 Hz、750 Hz、6000 Hz 正弦波与混合信号，验证低中高频定位、同频相位变化不横向移动、同时保留低频和高频、静音、DC 偏移、非法样本、采样率和未满分析窗口。灵敏度测试验证持续音量的稳定高度相同，敏捷设置对较小瞬态响应更明显；原有节拍余量及静音回落检查继续通过。

状态测试使用隔离的本机偏好域与模拟 HID：旧版自动启用偏好即使为真，新模型仍关闭；导航到音乐页或未经开启直接请求采集均不启动。音乐启停、静音灯帧、旧会话回调隔离、通知恢复和额度分区检查均通过。测试不读取真实账号，不向实体键盘发送报文，不启动真实系统音频采集。

## 界面

实际打开本地应用验证音乐开关为关闭。明亮、深灰主题均检查；音乐面板与两个设置入口可在默认窗口完整显示。鼠标点击设置行中间空白成功展开，点击右侧文字成功收起；展开后可见目标帧率和授权入口。此次界面验证没有开启音乐或调整实体灯效。

应用使用独立的全宽设置组件替换原有折叠菜单，保留按钮语义、辅助功能说明和减少动态效果支持。正式包重新编译、校验签名并检查源码归档与当前文件一致；打包回归覆盖凭据排除和失败保留旧包。

## 验证范围

真实听歌的主观动感、系统音频输入设备组合、RK98 的实体亮灯范围仍待用户验收。0.9 沿用 0.8 实时 HID 通道，此次验证不能证明其设备兼容性或消除闪烁。使用说明见 [0.9](FEATURES-0.9.md)。
