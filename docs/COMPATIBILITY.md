# 兼容性与验证等级

当前为 0.10 研究预览。FeralKey 没有全品牌通用控制协议，也没有运行时设备插件加载器。

## 设备

| 设备 | 匹配条件 / 本机证据 | 可用范围 |
| --- | --- | --- |
| RK98-100KRGB N，有线 | `258A:00C1`、USB、Usage Page 1 / Usage 128、Feature 65 字节、Report ID `0A` | 已实现基础灯光、逐键颜色和完整改键编码；离线校验及模型测试；实体效果需逐项验收 |
| Compx 2.4G 接收器 | `25A7:FA70`，已研究的 `bcdDevice=0391` 及精确描述符哈希 | 元数据识别；独立诊断的受限 Feature 06 读取；没有无线灯控 |
| RK98RGB 5.0，蓝牙 | BLE、`000E:3412`、BEKEN，标准软件版本 `02.0` | 独立诊断可读标准设备信息、电量；主应用没有蓝牙灯光后端 |
| 其他设备 / 批次 | 未匹配 | 只探索元数据；需要新增经过审阅的适配代码 |

同品牌、外壳型号相同、共用 VID/PID 或可以正常打字，都不足以放行其他设备的写入。两把相同控制接口同时出现时，应用要求只保留一把待测试键盘。

RK98 的公开匹配布局包含 **100 键**，物理位置、键码和 LED 协议索引不同；不能按产品名里的数字推算映射。

## 功能验证

| 范围 | 证据与限制 |
| --- | --- |
| 有线接口 | 开发机已枚举并匹配目标；权限受 macOS 输入监控和应用签名影响 |
| 配置灯光 / 改键 | 编码依据 Rangoli 的具体设备资料，完整事务有离线测试；不宣称所有批次已实物验证 |
| 分区合成、额度、通知恢复 | 模拟传输验证状态优先级、有效性、重连和异常路径；实物效果按清单检查 |
| 实时音乐与区域动画 | RK 家族实时协议资料不含本机 PID 的完整验证；须明确接受实验通道，45 / 60 FPS 为目标而非实测吞吐 |
| 系统通知 | 使用 Accessibility 观察通知中心横幅；不是稳定的第三方通知订阅 API，系统更新、专注模式等可能影响检测 |
| 原有配置备份 | 不支持；JSON 导出是 FeralKey 软件设置及接口信息，不是键盘固件或原配置备份 |

研究脚本打开设备成功、操作系统接受发送、返回状态值，均不能作为实际颜色、映射或刷新率已正确的证据。适配清单保留保守状态，只有可复现实物记录后才更新。

## macOS 与分发

- 最低部署目标：macOS 13；构建需 macOS 26+ SDK。旧系统材质回退、Intel 运行和不同音频环境尚未逐项实测。
- 开发环境：Apple Silicon；构建脚本只产出本机架构，不自动产生 Universal Binary。
- 主程序为本地临时签名，未 Apple 公证；重建可能使旧输入监控授权失效。
- 当前没有 Windows / Linux 应用。领域逻辑可复用，其他平台的 UI、音频、通知与 HID 传输需自行实现。
