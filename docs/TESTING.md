# 实物验收清单

离线测试通过不代表实际硬件兼容。只在[精确匹配的有线设备](COMPATIBILITY.md)上，由拥有者使用备用键盘逐项检查；2.4G / 蓝牙仅运行相应只读研究，不使用有线灯光报文。

## 开始前

- 记录提交编号、macOS、Mac 架构、键盘外壳型号、已知硬件版本及 USB 接口属性；不记录或公开唯一序列号。
- 保留备用输入设备，确认明白原配置无法读取备份。软件 JSON 导出不能恢复未知原映射或原灯光。
- 通过输入监控授权当前构建，完全退出后重新打开。先连接，不要同时测试改键和动态灯光。

## 建议顺序

| 步骤 | 操作与观察 |
| --- | --- |
| 1. 基础灯光 | 单色常亮，点击应用；观察颜色、亮度、键位和打字是否正常。再检查多彩及低亮度，界面草稿未应用时不应改变实体 |
| 2. 真实额度 | 确认数据有效，先单次同步；五小时 / 每周十个槽各对应 10%–100%，可单独启用、自选颜色；演示数据不能发送 |
| 3. 区域优先级 | 应用并固定额度区，改变基础配色；额度区应保留，通知重叠键也不应覆盖它 |
| 4. 通知 | 选择右侧数字区等键位，测试图案；通知显示五秒，静态图案呼吸；结束后该区恢复整体，额度区保持优先 |
| 5. 自动更新 | 选择间隔并观察读取时间；暂停应停止后续读取。实体同步另行开启，数据失效不发送；未开启时只更新屏幕 |
| 6. 实验动画 / 音乐 | 仅在前面正常且主动确认实时通道后测试。播放系统声音、手动开启，观察不同频率 / 音量的变化、是否闪烁或灯位错位；关掉应恢复基础灯光 |
| 7. 设置与重连 | 保存设置、完全退出再打开；偏好保留，音乐等待手动启动。重连后旧通知或旧帧不得继续生效，恢复依赖有效权限与数据 |
| 8. 改键（最后单独测试） | 清楚会覆盖完整默认映射加修改后，只选一个闲置键，应用并测试组合键；Fn 不参与。恢复默认只能恢复公开默认布局，不能还原原自定义配置 |

45 / 60 FPS 是调度目标，不能凭屏幕预览或发送成功确认实物帧率。微信等应用的系统横幅联动需授予辅助功能权限并先运行应用自己的测试横幅，随后单独记录目标应用、专注模式和检测结果。

发生断连、颜色错位、异常输入或持续闪烁时停止。不要反复重试未知命令；记录最小现象和时间，关闭实验功能后再决定是否按已知设置恢复。

## 记录结果

每项分别填写：成功 / 失败 / 未测试、具体连接方式、操作、观察结果与已脱敏证据。成功发出报告和正确显示颜色分别记录；不要把一个批次的成功推广到同型号所有设备。只有可复现实物记录后才更新对应适配清单的验证状态。
