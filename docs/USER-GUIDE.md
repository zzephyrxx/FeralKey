# 使用指南

## 首次连接

1. 确认设备属于[当前兼容范围](COMPATIBILITY.md)，用有线 USB 模式连接。无线模式不能控制灯光。
2. 在应用「连接与权限」入口找到当前构建；通过系统输入监控添加并允许它，完全退出后重开。遇到 `0xe00002e2` 见[权限排查](PERMISSIONS.md)。
3. 在探索向导阅读风险提示并主动确认。先只应用基础常亮灯效，观察颜色、亮度、按键和连接是否正常。

配置灯光会覆盖原灯光；软件没有键盘原配置的读取备份能力。保留备用键盘，不把第一次测试放在唯一工作设备上。

## Agent 额度灯

通过本机已登录的 Codex 读取套餐额度，无需把密钥或 Cookie 提供给 FeralKey。默认自动刷新屏幕读数，每分钟一次，可选择 30 秒、1 / 3 / 5 / 10 / 30 分钟。详细数据规则见[额度接入](CODEX-QUOTA.md)。

- 五小时和每周可分别开启，十个槽依次代表 10% 至 100%；选择对应键位、颜色后应用。
- 默认 F1–F10 对应五小时，数字行 1–0 对应每周；两组不能重叠。
- 实体自动同步由用户开启；固定额度区不受基础灯光和通知覆盖。
- 数据未知、失效或读取失败时停止发送。键盘仍保留上次成功快照，不应据此推断当前余额。

## 基础灯效与通知

选择单色 / 多彩、模式和亮度后点击应用。通知键位平时跟随整体，仅在通知时短暂显示，五秒后恢复；可选图案、颜色和动态预设，静态图案自动呼吸。

系统横幅检测是可选实验功能，需要辅助功能权限。微信等应用必须显示系统通知横幅；专注模式、通知中心状态、应用自绘窗口和 macOS 更新可能使检测失效。先使用应用测试横幅，再验证目标应用。

## 音乐实验室

应用系统音频权限后，播放系统声音并手动启用键盘律动。无需选择本地文件，不使用麦克风。可调灵敏度和目标帧率，默认 45 FPS，最高可选 60 FPS；如不稳定请降档或关闭。退出后再开不会自动启动音乐采集。

音乐及区域动画使用实验实时通道，首次另行确认。关掉后恢复本次已应用基础灯光；固定额度区继续保留。软件目标帧率不等于实际设备刷新率。

## 按键与工作流

在布局上选择按键，再选择普通键和修饰键组合，或使用预设。应用会写入整套默认布局加修改，覆盖未知的原自定义映射；Fn 层不由本项目改写。

可选全局快捷键 `⌃⌥⌘1` 执行灯光通知、计时、打开网址或已有 macOS 快捷指令。外部 URL `feralkey://notify` / `feralkey://focus` 会要求应用内确认；应用需保持运行。

## 保存与恢复

界面设置保存在本机；导入配置仅更新界面，仍需应用。重连后的恢复依赖成功应用记录、当前权限和有效数据；失败时保留偏好等待处理，不重放改键事务。导出的 JSON 不是键盘内部配置备份。

更完整的验证步骤见[实物验收](TESTING.md)。
